# Veda

A flip-through app of teachings from the Vedas, the Bhagavad Gita, the Ramayana and other old Indian scriptures, for phone and web with one shared login.

Each card shows the scripture name and verse reference, the Sanskrit, a transliteration, a translation and a short meaning, with two buttons: a **story moment** (with an illustration) and a **daily teaching** to apply. A gentle self-test tracks each reader's progress.

## Plan

1. **Content:** 30 cards (20 Bhagavad Gita, 10 Vedas) in `content/`.
2. **Design:** simple, modern, calm spiritual palette; clickable prototype of the flip, Today's verse, progress and the test.
3. **Build:** one Expo (React Native) codebase for iOS, Android and web; Supabase for accounts, progress and test scores; preload upcoming cards so flipping is instant.
4. **Illustrations and launch.**

See [docs/content-guide.md](docs/content-guide.md) for the card format and sources.
